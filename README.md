# BlockForge Mobile

This project has been upgraded into a more complete Android launcher prototype for mobile Minecraft Java launches.

## What is included

- version selection screen
- account selection
- device optimization presets
- modpack recommendation list
- launch configuration builder
- Java command generation and launch execution attempt
- custom app branding: `BlockForge Mobile`

## Build

Open in Android Studio, sync Gradle, and build an APK or install it on a connected device.

## Important note

This is a prototype launcher and does not include official Mojang game assets or a full desktop Java runtime bundle. The app builds a Java launch command and attempts to start Java if the device supports it.
